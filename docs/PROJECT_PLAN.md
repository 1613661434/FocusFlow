# FocusFlow 项目计划

## 1. 项目定位

- 中文题目：基于 C++/Qt 的个人任务规划与专注管理系统设计与实现
- 英文名称：FocusFlow
- 项目类型：面向个人用户的 Windows 桌面工具
- 核心目标：把“决定做什么、专心完成、回顾投入”放在同一个本地应用中
- 设计原则：无需登录、数据本地保存、操作直观、功能可验证、适合课程答辩演示

## 2. 用户与典型场景

系统不限定职业。学生可以管理课程和考试，职场人士可以管理项目和会议，
自由职业者可以管理客户任务，普通用户也可以记录生活事项。典型流程如下：

1. 创建项目、分类和任务，设置重要程度、截止时间与预计用时。
2. 在今日概览或“推荐”筛选中确定下一件要做的事。
3. 选择任务并启动专注计时，结束后进入短休息或长休息。
4. 通过桌面通知和自定义声音获知计时结束。
5. 在统计页回顾完成数量、专注趋势和时间分配。
6. 定期备份数据库或导出 CSV，保证个人数据可迁移。

### 3.2 后续增强（非本课程 MVP 必需）

- 循环任务、子任务、标签和日历视图
- 深色主题与更多无障碍选项
- 每日/每周目标以及更丰富的统计区间
- 开机启动、全局快捷键和勿扰模式
- 加密备份或用户主动配置的多设备同步
- 国际化与英文界面

## 5. 测试与验收计划

### 自动化测试

- FocusTimer：初始状态、自然结束、暂停时不消耗剩余时间。
- PriorityService：重要程度、逾期、短任务和进行中状态对分数的影响。
- DataManagementService：SQLite 备份、备份验证、恢复暂存和两类 CSV 导出。

### 人工验收

- 新建任务后，任务页、仪表盘和计时页同步显示。
- 计时暂停/继续正确，提前结束和自然结束均保存记录。
- 最小化后窗口隐藏到托盘，计时继续运行并能够弹出提醒。
- 自定义音频能够试听，播放达到限制时间后停止。
- 项目归档后不再出现在新任务选择项中，已有数据仍保留。
- 备份可通过完整性检查；恢复不会在当前进程直接覆盖数据库。
- 统计结果随着任务完成和专注记录变化而刷新。

## 6. 报告与答辩材料映射

工程实践报告可按以下顺序组织：

1. 绪论：个人任务碎片化、专注中断和数据隐私问题。
2. 需求分析：用户角色、功能需求、非功能需求和用例。
3. 总体设计：分层结构、模块划分、数据流与数据库 E-R 关系。
4. 详细设计：任务模型、优先级规则、计时状态机、提醒与备份流程。
5. 系统实现：Qt Signals/Slots、SQLite、Qt Multimedia、Qt Charts。
6. 系统测试：自动化测试结果与人工场景验收。
7. 总结展望：MVP 成果、限制与后续增强方向。

答辩演示建议使用“建任务 → 查看推荐 → 关联任务开始计时 → 模拟结束提醒
→ 查看统计 → 创建备份”的完整闭环，能够同时体现业务价值和 C++/Qt 技术点。

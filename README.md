# FocusFlow

FocusFlow 是一款使用 C++17、Qt 6 Widgets 与 SQLite 开发的 Windows
个人任务规划与专注管理工具，当前版本为 **v0.1.30**。

中文定位：**个人任务规划与专注管理系统**

英文名称：**FocusFlow — Personal Task Planning and Focus Management System**

项目地址：[https://github.com/1613661434/FocusFlow](https://github.com/1613661434/FocusFlow)

系统面向学生、职场人士、自由职业者以及希望改善个人时间安排的普通用户。
它把“规划任务、选择下一项行动、进入专注、安排休息、回顾时间投入”放在同一
个本地桌面应用中，无需注册账号，也不依赖云服务。

## 核心特点

- **本地优先**：任务、设置和专注记录保存在本机 SQLite 数据库中。
- **任务闭环**：从任务创建、优先建议到关联专注和统计回顾形成完整流程。
- **可解释推荐**：推荐分由重要程度、截止时间、逾期程度、预计耗时和任务状态共同计算。
- **准确计时**：倒计时使用系统时间校正，窗口最小化或短暂卡顿不会持续累积误差。
- **多种节奏**：可为不同任务绑定不同专注方案，也可在开始前临时配置并保存完整方案。
- **操作安全**：永久删除前确认；备份恢复前验证并自动保护当前数据库。
- **界面一致**：项目、分类、重要度、推荐分和状态在不同页面保持一致的颜色语义。

## 功能总览

### 今日概览

- 显示待处理、今日到期、已逾期、今日完成和今日专注时长。
- 今日专注精确显示到秒。
- 按推荐分从高到低展示优先建议。
- 可按项目和分类筛选建议，项目与分类名称使用各自设置的颜色。
- 双击建议可直接进入专注计时，并自动选中对应任务。

### 任务管理

- 新建、编辑、完成、重新打开和永久删除任务。
- 支持任务标题、详细描述、项目、分类、1～5 级重要度、截止时间、预计耗时和默认专注方案。
- 新任务默认启用“今天 23:59”作为截止时间，也可以关闭截止时间。
- 支持全部任务、智能推荐、今日任务、未来 7 天、已经逾期和已完成筛选。
- 支持搜索任务、项目或分类，点击任意列标题即可排序。
- 任务表直接显示绑定的专注方案；未绑定时显示当前实际全局默认方案。
- 截止时间完整显示年份；逾期任务使用红色提示。
- 点击“完成”或重新打开任务后会刷新状态并取消当前选择，防止排序导致选中行跳动或连续误操作；按钮文字始终保持“完成”。
- 任务删除后，已经产生的专注历史仍会保留，并显示为“无关联任务”。

### 项目与分类

- 项目支持新增、编辑、归档、恢复和永久删除。
- 分类支持新增、编辑和删除。
- 项目与分类均可选择颜色；颜色会同步显示在任务、概览、专注和统计页面。
- 删除项目后，其任务保留并变为“无项目”；删除分类后，相关任务变为“未分类”。
- 表格所有列居中显示，支持按列排序；项目状态可控制归档项在前或在后。

### 专注计时

- 内置经典番茄钟、快速处理、深度工作和长时专注方案；内置预设保持固定，不能修改或删除，可复制后自定义。
- 每个方案可独立设置专注、短休息、长休息、长休息间隔及自动衔接行为。
- 任务可绑定默认方案；未绑定时跟随系统默认方案，开始前仍可临时切换。
- 可选择“自定义本次方案”，独立设置专注、短休息、长休息、长休息间隔和两项自动衔接行为。
- 自定义修改点击“确定”后才应用；确认后可输入名称“保存为方案”，方便下次直接复用。
- 保存自定义方案时自动建议可用名称；已有“我的专注方案”后依次使用“我的专注方案2、3……”避免重名。
- 选择“自定义本次方案”后直接展开编辑项，不再重复显示同名标题；操作按钮、长休息间隔和自动衔接选项不会被裁切。
- 主按钮根据状态在“开始 / 暂停 / 继续”之间切换，另设“终止”按钮。
- 可按项目、分类筛选关联任务；任务按推荐分从高到低排列并显示推荐分。
- 专注正常结束或被终止后都会保存实际用时；终止关联任务的专注时可选择是否同时完成任务。
- 休息时间会保存为记录，但不会计入专注统计。
- 支持专注结束后自动开始休息、休息结束后自动开始下一轮专注。

### 提醒与窗口行为

- 计时自然结束时显示桌面通知，并可播放系统默认提示音或自定义声音。
- 专注结束声音和休息结束声音可分别设置。
- 支持 WAV、MP3、AAC、M4A、OGG 和 FLAC。
- 可调节音量、最长播放时间和播放次数；自定义声音达到限制前会平滑淡出，且不会修改原始音频。
- 自定义声音会复制到应用数据目录；更换或恢复默认后会清理不再使用的托管副本。
- 最小化窗口时仍保留在任务栏；关闭窗口时隐藏到系统托盘。
- 只有从托盘图标右键菜单选择“退出”，程序才会真正结束。
- 鼠标悬停托盘图标可查看任务、专注/休息状态及实时剩余时间，休息阶段仍统一显示“任务”。
- 关闭到托盘提醒可在设置中关闭或重新开启。
- 程序采用单实例运行；再次打开 FocusFlow 会直接恢复原窗口，不会创建第二套界面。

### 数据统计

- 汇总今日专注、近 7 天专注和今日完成任务数量。
- “图表分析”页显示近 7 天专注柱形图、近 30 天分类占比和项目占比。
- 鼠标移到柱形上时，柱顶正上方居中显示无边框的精确秒数。
- 分类和项目饼图为相邻小扇区错开外侧引导线，避免标签文字重叠。
- “最近记录”页一次显示最近 10 条专注记录，无内层滚动条。
- 最近记录包含编号、开始时间、任务、项目、分类、时长和结果，并支持所有列排序。
- 已完成与已终止、进行中与已归档、待处理与已完成均使用不同的语义颜色。

### 设置与数据管理

- 用户方案支持新建、编辑、复制、设为默认和删除；内置预设只读，但可复制为用户方案。
- 专注方案表所有列均可排序，默认按“默认、系统默认、系统预设、用户自定义”的状态顺序显示。
- 专注方案表固定显示 5 行，更多方案在表内滚动；表格必须先被点击选中才响应滚轮，获得焦点后即使滚到边界也不会带动外层页面。
- 选择方案行后可点击方案卡片、说明或页面空白取消选中；计时页方案下拉框点击空白后也会退出焦点状态。
- 声音和窗口行为修改后统一保存。
- 设置尚未保存时切换页面，会询问“保存并切换 / 放弃修改 / 取消切换”。
- 数值框和音量滑块只有获得焦点后才响应滚轮，避免与页面滚动冲突。
- 支持 SQLite 一致性备份、备份验证和下次启动恢复。
- 支持导出任务 CSV 与专注记录 CSV，文件采用 UTF-8 BOM，便于中文表格软件打开。
- 可以清空全部专注与休息记录，同时保留任务、项目、分类和设置。
- 设置页提供版权信息、作者资料、作者博客和项目 GitHub 入口。

## 推荐分算法

推荐分用于“今日概览”“智能推荐”和“关联任务”排序。已完成或已取消任务的
推荐分为 0，其余任务按以下规则累加：

| 因素 | 分值 |
|---|---:|
| 重要程度 | `等级 × 20`，即 20～100 分 |
| 已逾期 | 40 分基础加分，再按逾期天数增加，最多再加 20 分 |
| 12 小时内到期 | +35 |
| 24 小时内到期 | +28 |
| 3 天内到期 | +18 |
| 7 天内到期 | +8 |
| 预计耗时为 1～25 分钟 | +5 |
| 状态为进行中 | +10 |

该算法是确定性的规则模型，不使用网络服务或用户隐私数据，便于用户理解、
自动化验证和长期维护。

## 开发环境

- CMake 3.21 或更高版本
- Qt 6.5 或更高版本，包含 Widgets、Sql、Multimedia、Charts、Network 和 Test
- 支持 C++17 的编译器
- Ninja（推荐）

当前已验证环境：

- Windows 10/11
- Qt 6.10.0
- MinGW 13.1
- Ninja

## 构建与测试

在 PowerShell 中进入项目目录：

```powershell
cd D:\Qt\Projects\FocusFlow
```

使用当前开发环境的脚本：

```powershell
.\tools\build.ps1
```

脚本会依次执行 CMake 配置、编译和全部自动化测试。成功后程序位于：

```text
build/FocusFlow.exe
```

如果 Qt、Ninja 或 MinGW 安装位置不同，可手动配置：

```powershell
cmake -S . -B build -G Ninja `
  -DCMAKE_BUILD_TYPE=Release `
  -DCMAKE_PREFIX_PATH=D:/Qt/6.10.0/mingw_64 `
  -DCMAKE_MAKE_PROGRAM=D:/Qt/Tools/Ninja/ninja.exe `
  -DCMAKE_CXX_COMPILER=D:/Qt/Tools/mingw1310_64/bin/g++.exe

cmake --build build --parallel 4
ctest --test-dir build --output-on-failure
```

也可以使用 Qt Creator 打开根目录的 `CMakeLists.txt`，选择包含 Qt Charts、
Qt Multimedia 和 Qt SQL 的 Qt 6 Kit 后构建。

## Windows 打包

```powershell
.\tools\package.ps1
```

打包脚本会重新执行 Release 构建和全部测试，随后调用 `windeployqt` 收集 Qt
运行库与中文翻译文件，最终在 `dist/` 下生成独立目录和 ZIP 压缩包。

## 本地数据与恢复

数据库的准确位置显示在“设置 → 数据管理 → 本地数据库位置”。同一应用数据目录
还会保存托管声音、自动保护备份和待恢复数据库。运行数据、个人音频、构建目录和
打包产物均已加入 `.gitignore`，不会写入 Git 历史。

恢复流程不会在程序运行时直接覆盖已经打开的 SQLite 文件：系统先验证所选备份，
再一致性备份当前数据库并暂存恢复文件；退出并重新打开 FocusFlow 后才执行替换。

## 自动化测试

项目当前注册 12 个 CTest 测试目标，覆盖：

- 倒计时开始、暂停、继续、自然结束和系统时间校正基础行为。
- 推荐分计算。
- 专注页面按钮状态、完整自定义方案确认与保存、短暂反馈、任务筛选、方案绑定、托盘倒计时、推荐分展示和排序。
- 专注方案默认数据、内置只读约束、用户方案增删改及任务删除方案后的回退行为。
- 新任务默认截止时间、中文日历和时间输入。
- 数值框、滑块和内嵌方案表的焦点滚轮保护行为。
- 数据库备份、恢复验证、CSV 导出、统计清空和声音副本清理。
- 概览、统计、表格排序、颜色同步、永久删除与历史数据保留。
- Qt 标准按钮中文化。
- 版权信息和作者链接。
- 单实例锁、重复启动通知和主实例退出后的锁释放。
